\\section{Motivation and Target Relationship}
Target relationship: \\texttt{dsm\\_mfront\\_hierarchical} should stand to \\texttt{dsm\\_mfront} as \\texttt{dsm\\_native\\_hierarchical} stands to \\texttt{dsm\\_native}, expressed through MFront bridge mechanisms.

\\section{Semantic Porting Objective}
This is a semantic port. The native patch recipe was used to identify behavior deltas; implementation was translated into MFront-native extension points.

\\section{Native Hierarchical Delta Analysis}
Key native deltas used as semantic targets:
\\begin{itemize}
\\item Hierarchical porosity relation linking $\\phi$, $\\phi_M$, $\\phi_m$, and $n_l$.
\\item REV-consistent micro mass storage using $\\phi_m \\rho_{lR}$ instead of flat $n_l \\rho_{lR}$.
\\item Consistent swelling/mass-exchange coupling under the hierarchical split.
\\end{itemize}

\\section{How dsm\\_mfront Encodes DSM Behavior}
In the MFront branch lineage, DSM micro-macro behavior is concentrated in \\texttt{RichardsMechanicsDSMMicroMacroBridge\\_MCC.mfront}, with RM process plumbing consuming bridge state variables.

\\section{Porting Strategy}
Apply hierarchical semantics where the bridge still assumes flat micro-porosity:
\\begin{itemize}
\\item map $n_l$ to REV micro-porosity via hierarchical conversion,
\\item update residual and previous-mass terms to use converted $\\phi_m$,
\\item keep changes local and reversible.
\\end{itemize}

\\section{Implemented Subsystem Change}
Implemented in \\texttt{MaterialLib/SolidModels/MFront/RichardsMechanicsDSMMicroMacroBridge\\_MCC.mfront}:
\\begin{itemize}
\\item Added \\texttt{phi\\_m\\_from\\_n\\_l(...)} conversion under fixed trial total porosity.
\\item Replaced \\texttt{previous\\_mass = n\\_l\\_prev * rho\\_lR\\_prev} with \\texttt{phi\\_m\\_prev * rho\\_lR\\_prev}.
\\item Replaced residual mass terms from \\texttt{n\\_l * rho\\_lR} to \\texttt{phi\\_m(n\\_l) * rho\\_lR}.
\\item Updated trial-state \\texttt{phi\\_m} and \\texttt{phi\\_M} assignment to hierarchical mapping.
\\end{itemize}
