# BEACON WP3 BGR EPFL Replay

This folder contains the reduced replay assets for D3.3 Annex A (BGR path
`P2-1`, stage `A-B'`).

- replay project files (`*.prj`),
- geometry/mesh inputs (`*.gml`, `*.vtu`),
- analysis and plotting scripts (`*.py`),
- report-style figures and series (`*.png`, `*.csv`, `*.json`).

Run provenance (including git hashes) is tracked in:
- `Tests/Data/RichardsMechanics/test_run_table.csv`
